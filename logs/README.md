
# Logs Folder

This folder contains training and execution logs generated during different stages of the Multimodal Emotion Recognition and Sentiment Analysis project.

The logs are useful for tracking model training progress, debugging errors, monitoring performance, and reviewing experiment behavior. Each log file may include details such as epoch-wise training loss, validation loss, accuracy, model checkpoints, runtime messages, warnings, and errors.

This folder helps maintain a clear record of how each experiment was executed and makes it easier to compare different training runs. It is especially useful when training unimodal models such as text, audio, video, and face models, as well as multimodal fusion models.

The logs can be used to:

- Monitor training progress across epochs
- Track validation and testing performance
- Debug failed or incomplete training runs
- Compare baseline and improved experiments
- Identify overfitting, underfitting, or class imbalance issues
- Keep experiment history organized

This folder supports better reproducibility and experiment management by storing important runtime information from the training pipeline.
