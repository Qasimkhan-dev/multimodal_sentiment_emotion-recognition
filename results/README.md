
# Results Folder

This folder contains the evaluation results generated after training and testing the unimodal and multimodal models for the Multimodal Emotion Recognition and Sentiment Analysis project.

The results are saved as JSON files and include performance metrics for both main tasks: emotion recognition and sentiment analysis. Each file corresponds to a specific model or fusion configuration, such as text, audio, video, face, 3-modality fusion, and 4-modality fusion.

These result files help compare the performance of individual modalities with multimodal fusion approaches. They also provide a clear record of model accuracy and evaluation outcomes, making it easier to analyze how different modalities contribute to final prediction performance.

The folder includes results for:

- Text-based models using RoBERTa
- Audio-based models using Wav2Vec2
- Video-based models using MobileNetV2 and Transformer
- Face-based models using InceptionResNetV1 and BiLSTM
- 3-modality fusion models
- 4-modality fusion models

This folder is important for tracking experiments, comparing reproduced results with the original paper, and understanding the effectiveness of each model configuration.
