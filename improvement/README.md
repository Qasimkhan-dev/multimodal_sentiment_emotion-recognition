
# Improvement Folder

This folder contains the improved and extended version of the Multimodal Emotion Recognition and Sentiment Analysis project.

The purpose of this folder is to address limitations observed in the initial reproduction results and improve the overall performance of the system. In the original implementation, some unimodal models, especially audio, video, and face models for emotion recognition, showed limited performance due to class imbalance and majority-class prediction behavior. This improvement section focuses on solving these issues using better training strategies, improved model handling, and more reliable evaluation.

The improvement pipeline may include changes such as weighted loss functions, better class balancing, optimized training configurations, improved feature extraction, enhanced model architectures, and more stable fusion methods.

This folder helps separate the original reproduction code from the improved experimental version, making it easier to compare baseline results with enhanced results.
