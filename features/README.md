# Features Folder

This folder contains the extracted feature embeddings generated by the trained unimodal models in the Multimodal Emotion Recognition and Sentiment Analysis project.

Each `.pt` file stores learned feature representations for a specific modality, task, and dataset split. These features are extracted from text, audio, video, and face models after training and are later used as input for multimodal fusion models.

The feature files help avoid retraining unimodal models repeatedly. Instead, the fusion models can directly load these saved embeddings and combine them to perform final emotion recognition or sentiment analysis.

This folder includes feature embeddings for:

- Text features extracted using RoBERTa-base
- Audio features extracted using Wav2Vec2-base
- Video features extracted using MobileNetV2 + Transformer
- Face features extracted using InceptionResNetV1 + BiLSTM
- Train, development, and test splits
- Both emotion recognition and sentiment analysis tasks

These saved features are essential for training the 3-modality and 4-modality fusion models, where embeddings from multiple modalities are concatenated and passed into an MLP classifier.
